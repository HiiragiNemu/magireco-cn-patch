# 事件剧情结构标题汉化（2026-08-20）

本轮只处理 `eventStoryList.json` 中用于列表和章节导航的结构标签，不修改任何 scenario 剧情脚本或对白。

- `Story` → `剧情`
- `Prologue` → `序章`（同文件已有 8 条中文惯例）
- `Record Ⅰ…Ⅹ` → `记录Ⅰ…Ⅹ`
- `Intermission` → `幕间`
- `Epilogue` → `尾声`
- `TRUE END` → `真结局`
- `N话(End NoX)` → `N话（结局X）`
- `N话(TRUE END)` → `N话（真结局）`

共修改 **69** 个结构字段；其余事件标题、角色台词、`Magia` 等官方术语均未改动。
