# 称号与战斗漏译修正

- 数据分母：日服 TopPage 的 967 个静态称号，名称与解锁条件共 1,934 字段。只保存静态称号数据，未保存账号数据。
- 可用旧国服 Full_Raw_Dump_V2 中没有 `titleList` / `userTitleList`，因此不把称号译文标为官方来源。
- 名称：545 个记录采用中文 Wiki《称号》已有译文；420 个记录采用既有角色中文名与 Wiki 的“回忆 / 光辉”格式；2 个 Wiki 缺失条目按日文单独翻译。
- 全角数字与“奧 / 奥”的差异只用于构建时比对 Wiki。运行时仍要求原始完整字符串一致，不做宽泛模糊替换。
- 解锁条件：逐条保留原始等级、章节、名次、活动限定，角色名沿用当前角色字典，活动名参考对应 Wiki 条目。
- 不计空白条目；这些字段暂未并入公开贡献数量，避免把接入工作误记为原创翻译。

运行时只在 `titleList`、`title`、`displayTitle` 中识别带有 `title_数字` 背景的称号记录，按稳定 ID 和原字段精确匹配。已翻译或源字段发生变化的记录不被强制覆盖；图片、字体、排序与解锁状态不变。

原生战斗表补入用户截图中的 `ダメージカット無視 & 全状態異常無効` 以及单独的 `全状態異常無効`，不增加字体、位置、加载或全局子串替换逻辑。

检查：`node tools/test-title-localization.cjs .` 使用完整注入器验证所有记录的三种载体、嵌套响应、非文本字段和重复应用。传入第三参数基线根目录时，另比较 4,835 个负例，并统计基线漏译。

发布渠道：`cn_js_delta.zip`，在 APK 188 支持的第 16 槽最后应用；固定 JS 102 与 scenario 3299 保持不变。技术测试与用户实机验收分开记录。
