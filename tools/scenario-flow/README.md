# scenario-flow —— 魔纪 ADV v3 的流程层

《魔法纪录》的场景脚本（`madomagi/resource/scenario/json/`）是 JSON，不需要反汇编，
但**剧本怎么跳转**这件事没有人写下来过。这份文档把它写清楚，
`analyze.py` 负责把每个数字重新跑出来。

```bash
python3 tools/scenario-flow/analyze.py            # 全库跑一遍
python3 tools/scenario-flow/analyze.py --json out.json
```

退出码非 0 表示有**可证伪的检验**没过 —— 那说明下面某条结论已经不成立了，
先改结论，别改检验。

## 为什么要解这一层

`puellamagi-legacys-general-web-client` 的播放器要把场景编译成「可执行的程序」
才能走分支。它的流程契约（`vn.flow`）按那边的规矩得有**两份跑起来的实现**才能落笔，
携带版（PSP）是第一份，魔纪是第二份。两边形状差得越远，撞出来的契约越结实 ——
事实也是这样，见末节。

**本目录不产 IR，也不进热更包。** 它只解读现有数据，不改任何东西。

## 语料

当前待发布的 `cn_scenario_update` 工作树共有 14233 个文件、414579509 字节。其中：

| | 个数 |
|---|---|
| 正常场景（`story` 是组字典） | 14232 |
| `story` 直接是块数组（没有组名） | 1（`adv/scenario_4/400000-0.json`） |
| **无法解析的 `.json`** | 0 |

共 31843 个组、709322 个块。

> 历史包曾把 29 个「NewVersionRecommend」HTML 版本提示页误存成 `.json`。
> 其中 28 个已从现代脚本源恢复，保持控制流和演出字段不变，并补齐中文正文、说话人
> 与选项；唯一没有剧情引用、也没有有效原稿的 `adv/scenario_9/900101-060.json` 已从包中
> 移除。客户端会按场景目录清单清理旧副本。自此任何非 JSON 文件都会使分析器退出失败。

## 已确认

判据只有一条，与携带版那边用的是同一条：**跳转目标必须落在同一文件已有的组上**。
它可证伪 —— 只要有一处落空，整套读法就不成立。

### 段就是组

`story` 是 `{组名: 块数组}`，组名恒为 `group_N`。**入口恒为 `group_1`**
（14204/14204 个组字典形状的文件都有它）。

### 两个流程键，没有第三个

全库 708565 个块的键里，控制流只有这两个，**没有任何 condition / flag / if 类键**：

| 键 | 形状 | 处数 | 文件数 |
|---|---|---|---|
| `select` | `[{group, textSelect, alternativeId?}]` | 307 | 179 |
| `changeGroup` | 组名字符串 | 127 | 57 |

- `select` 共 686 个选项，每处 1 / 2 / 3 个（16 / 203 / 88 处）。
  **686 个目标组全部存在于同一文件，0 处落空。**
- `changeGroup` **127 个目标组全部存在，0 处落空**，并且**恒在组尾**（127/127）。
- `select` 是组里最后一个**有内容**的块：301/307 就是最后一块，
  其余 6 处后面只跟纯演出块（`autoTurnLast` / `turnChangeIn` / `bgm`），
  不带文本也不带流程。

### 组之间不会自动落下去（已排除 fall-through）

两条独立证据：

1. **127 处 `changeGroup` 里有 63 处的目标就是紧邻的下一组。**
   要是组走完会自动落进下一组，这 63 处就是白写的。
2. **语义上说不通。** `adv/scenario_5/501701-13.json` 里 `group_1` 以 select 收尾，
   两条支路 `group_2`（『做作业』）与 `group_3`（『去书店』）都以「无出口」结束。
   若会自动落，选了『做作业』之后会接着播『去书店』的台词。

所以：**组走完就是场景结束**，除非显式 `changeGroup` 或 `select` 跳走。

### 流程图的形状

179 个带流程的文件里：

- 组数 2..7（分布 `{2:7, 3:1, 4:117, 5:47, 6:1, 7:6}`），**最多 7 组**；
- **没有环，没有选项指向自己**；
- 4 个文件里选项段内还有选项（两处选项串起来，如 `adv/scenario_1/101202-6.json`：
  `1 →(选) 2/3 →(汇合) 4 →(选) 5/6 →(汇合) 7`）；
- 汇合是常态：170/179 个文件里至少有一个组的入度大于 1。

### `adv/` 之外的 `group_N` 不是控制流

`json/general/` 与 `json/charaOneShot/` 里有 422 个多组文件（最多 75 组）
**一个流程块都没有** —— 那里的 `group_N` 是宿主按外部索引挑一组用。
判据是反过来的：`adv/` 里**多组文件必定带流程**（179/179），
这两个目录里 422/422 都不带。所以流程这套读法**只对 `adv/` 成立**。

## 尚属推测

- **`alternativeId`**（686 个选项里 380 个有）是什么。没有判据，所以不进产出。
- 那 6 处 `select` 之后的纯演出块会不会被执行。
- 111 个 `adv` 文件各有 1 个从 `group_1` 到不了的组，**全部带 `select`**
  （98 个重复了可达组里的同一处 select，13 个是不同的 select）。
  形状像「宿主另外进入的入口」，但**怎么进入没有解出来**。
  `general/` 那种「按外部索引挑组」是同一类机制的可能性存在，同样没有判据。

## 已排除

- **fall-through**，见上。
- **引擎有状态/数值机制**：全库没有任何 condition / flag / if 类键，
  `select` 的目标是死的组名。所以感情值那类阈值判定在魔纪 ADV 里**表达不出来**
  （`tools/story-import/README.md` 末节说的就是这件事）。

## 与携带版对照：契约被逼出来的两条

`puellamagi-legacys-general-web-client` 的 `vn.flow` 契约就是从这两边撞出来的。
两条结论，凭空设计想不到：

| | 携带版（PSP） | 魔纪（ADV v3） |
|---|---|---|
| 段 | 标号把指令流切出来的区间 | JSON 里的 `group_N` |
| 玩家选项 | `Choice`：提示 + n×{文本, 附注, 目标标号} | `select`: n×{textSelect, group} |
| 无条件跳转 | `Jump 目标标号` | `changeGroup` |
| 条件跳转 | 370 处 | **没有** |
| 段走完 | **落进下一段**（1567 个段里 537 个靠这个） | **结束**（63 处冗余跳转为证） |

1. **跳转的目标只能是段名，不能是「第几条指令」。** 魔纪根本没有全局指令流。
2. **「段走完之后去哪」必须是数据的一部分。** 两边给的值正好相反，
   任何一边写死都会把另一边逼成编值。

## 检验清单

`analyze.py` 每次跑都会重跑这几条，任何一条不过就是结论被证伪：

- `select` 的目标组都在同一文件里
- `changeGroup` 的目标组都在同一文件里
- `changeGroup` 恒在组尾
- 带流程的文件里没有环
- 没有选项指向自己

1 个块数组形状的文件仍单独记录；非 JSON 文件不再属于容忍项，会直接使检验失败。
