# 已验证客户端与资源发布隔离

客户端发布只接收成功的既有主线构建产物。完整APK与版本旁注在公开入口就位且摘要、大小、构建编号一致后，才提升公开配置的客户端版本。

公开剧情和脚本可以由独立工作持续更新，版本可能高于客户端构建来源仓。客户端发布不得因此调用完整资源镜像，也不得关闭资源防回退检查。专用提升工具只读取两个客户端资产及当前公开配置，用文件SHA比较交换更新客户端身份和时间；保留公开配置所有其他字段，绝不写入资源包、剧情/脚本版本或资源清单。

同版本同摘要重试保持幂等；同版本不同包、旧版本、新旧资产不一致、非已批准构建、并发配置变化均拒绝。原完整资源镜像及其防回退规则保持不变。

`tools/test-client-only-publication.py` 包含公开资源更高版本、正文内容字段保留、客户端回退、同版本冲突、错误构建编号、旁注不符及并发配置保护等反例。

验证记录：专用发布测试12项及原完整镜像测试17项通过。既有静态镜像名称检查仍要求旧线路名称，与当前未改动的配置不符；本次不修改线路名称或关闭检查。
