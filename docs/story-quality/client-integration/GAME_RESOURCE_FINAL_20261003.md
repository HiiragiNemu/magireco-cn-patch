## 源仓未来私有化

玩家只需要独立公开仓库与 Cloudflare 入口，不需要私有源仓访问权。发布程序根据源仓可见性采用认证 API 回读；公开目标始终匿名核验。镜像工作流使用 SOURCE_TOKEN 读取源仓，TARGET_TOKEN 写公开仓库；临时 Git 认证仅限源仓 URL，退出后清除，不写入配置和制品。

保持已有 schedule/workflow_run/push 联动及共用发布锁；私有仓 Actions 可用额度、GH_TOKEN 对两个仓库的权限必须仍有效。后续客户端仍以人工明确的已实测 APK 摘要触发发布，私有化不放开此门。
