## 先纠正“剩余50”的来源判断

旧清单以机器导入历史为基础，但其中一些文件后来已有权威修复。不能仅凭文件曾经经过机器导入，就把现在的人工作品重新算作机翻。

50个路径全部核对后：23个属于519项固定人工中文变体恢复清单，1个主线片段103105-11_32rIq已在旧提交完成日文全文复核并应用。这24项不重译、不建立新候选、不新增计功。另26项才是本轮需要校订的残余机器内容。

23项人译中，两项的当前版本与历史锁定blob不同，但逐字段差异只是既往修正过的梅丽莎完整姓名；另一项的旧canonical副本后来追加嘴部控制，而本次目标仍是原锁定的人译正文。均核对了实际变更，不把旧清单blob硬覆盖回现行版本。当前姓名、中文和各仓控制位置原样保留。

原有14个已恢复字段也独立锁定：10个旁白姓名、4个正文。本轮候选与这些字段零交集。3个混合载荷片段设置了正向白名单：第一部主线只修3个fallback，两个MVD片段分别只修1个fallback；其余中文及漫画括号标注不改。

来源核定脚本最初被历史姓名/canonical版本差异阻断，随后又发现字段审计器不能用正文列表读取nameNarration。两处均通过实际源blob与JSON地址完成修正，失败记录保留；没有跳过保护校验。早先中途说明中的排除结论，已由后续实际执行的来源分账与守卫补齐。
