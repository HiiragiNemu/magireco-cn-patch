# 资源同步读取失败续修

## 证据与范围

资源配套一致性修复后的两次同步已经成功，但后续运行 37054831061 又在读取阶段附近失败。现存日志只有 HTTPError 类型，且旧入口仅在成功后生成报告，故没有保留原始 HTTP 状态。不能据此把这次失败重新归因于版本回退或声称已确定某个状态码。

本次复验的配套资源仍为 Scenario 3323、完整 JS 103、累计补充 22。两个发行仓九项包与清单身份一致，实际 ZIP 的 14,233 个剧情文件匹配已核定生产源码，128 个交叠路径零冲突。读取恢复不是跳过完整性或版本检查。

## 最小变更

只对未开始读取响应正文、无请求体的 GET，在 HTTP 500/502/503/504 时进行最多三次请求，间隔一秒、两秒。权限、限流、缺失和身份校验失败不自动重试；写入操作保持单次。原重定向白名单与授权头剥离保持不变。不增加正常成功请求的次数。

失败出口也写入结构化报告，保留安全的操作标识、HTTP 状态与次数。报告不保存签名地址、查询参数、认证头或远端异常正文；报告失败不等同于断言所有变更已经回滚。既有发布边界和版本/摘要核验未修改。

新增 12 项传输测试覆盖正常读取、四类暂时失败、次数上限、四类写请求禁止重试、缺失与权限/限流错误、可选 404 语义、摘要拒绝、凭证脱敏及前置失败报告。原 17 项镜像政策、5 项资源层、7 项发布事务和 30 项传输代理断言仍需通过。

实际同步结果以随后运行及发布附件身份复验为准，本记录不把本地测试等同于线上已经成功。没有改动玩家包、客户端布局、Reader、网页或未发布翻译候选。
